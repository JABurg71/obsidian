This is an issue that I know that I'm going to have to address. Whether to continue using Notepad++ or start using Obsidian again. 

Before I go into the details of the comparison, I want to lay out some of the things that I wanted to accomplish with this system:
- I wanted a place to store many files
- Easy searchability
- Plain Text
- Easy to format
- No vendor locking

Obsidian has the advantage of rendering markdown. So it's much easier to read. 
Notepad++ is faster. It's easier to create a new file, open a new file. 
Notepad++ can handle code and text
Obsidian is a file management system. 
Notepad++ can handle massive files and more obscure file types

There's a tremendous use for both apps. What I need to do is delimit what app is used for and what they are not used for. 

General notetaking and project tracking should be done in Obsidian. 
Viewing code, opening large text files, or opening none standard files should be done in Notepad++
